ServiceHub Marketplace is a web-based platform that connects customers in Meru, Kenya, with local service providers such as plumbers, electricians, carpenters, painters, and refrigeration technicians.

Features

Browse service providers by category.

Search and filter providers.

View provider profiles, ratings, locations, and starting prices.

Save favourite providers.

Submit service enquiries.

Contact providers through WhatsApp.

Responsive design for desktop and mobile devices.
